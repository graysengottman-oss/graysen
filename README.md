# Graysen
## Personal Portfolio
Welcome to my personal portfolio website. This site showcases my photography, political research, newspaper work, and other projects.
### Sections
- **Home** — Introduction and profile
- **Photography** — Photography projects and photos
- **Political Research** — Political research and written work
- **Newspaper** — Newspaper projects, articles, and work
### Features
- Responsive design for phones, tablets, and computers
- Photography gallery
- Photo captions
- Political research cards
- Newspaper section
- Profile photo
- Portfolio editor
- Smooth animations and page transitions
- Support for up to 25 photos
### Built With
- HTML
- CSS
- JavaScript
- GitHub Pages
### Files
`index.html` — Main website
`portfolio-data.json` — Portfolio information and content
`Images/` — Images used by the website
### Website
This portfolio is hosted using GitHub Pages.
